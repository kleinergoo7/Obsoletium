# REPRODUCE.md — rebuild everything from a fresh clone

This repo tracks source, build scripts, tools and documentation only. Everything else
is either fetched from Steam, generated by a script listed here, or generated by
`git` itself. A fresh clone plus this page reproduces the project.

## 0. What is NOT in git, and how each one comes back

| Path | Why it is ignored | How to recreate |
|---|---|---|
| `css-steam-assets/` | Valve game content (Steam appid 240) | Copy/point the CS:S + HL2 install here. Read-only: nothing writes into it. |
| `build*/` | Build output | `./tools/build.sh` (see §3). |
| `cmake/generated/` | Generated from the `.vpc` files | `python3 tools/vpc2cmake.py --root . --out cmake/generated` |
| `game/` | Generated game root | `./tools/make-gamelink.sh` |
| `game_client/` | Generated run tree + shader pack | `./tools/prepare-run-tree.sh` (see §5) |
| `docs/env.lock` | Host-specific version snapshot | `./tools/setup-env.sh --lock` |
| submodule contents (`thirdparty/*`, `ivp`, `external/vpc`) | gitlinks, as upstream | `./tools/fetch-submodules.sh` (rewrites SSH URLs to https) or `git submodule update --init --recursive` after `git config url."https://github.com/".insteadOf git@github.com:` |
| `logs/` | Run/build history | Not reproducible; not needed. Recreated by `tools/build.sh` and each run. |
| `__tmp/` | Scratch | Not needed. |
| `research/` | Read-only reference engine (nillerusr) | `git clone https://github.com/nillerusr/source-engine research/nillerusr-source-engine && git -C research/nillerusr-source-engine checkout ed8209cc` |
| `.git-obsolete-backup/` | Original Obsoletium history before the flatten | `git clone https://github.com/kleinergoo/Obsoletium` and check out `606c49a4d`. No local commits exist in the backup; all refs point at that commit. |

Nothing else is ignored. `game_client/vulkan/` (the shader pack) is the only large
derived artifact; §5 rebuilds it.

## 1. Host

openSUSE Leap 16.0, GCC 15 / Clang 19, CMake 3.31, Ninja, Python 3.13, SDL3, Vulkan
loader + validation layer, `glslangValidator`, `spirv-val`, `spirv-cross`. Exact
versions are captured by `./tools/setup-env.sh --check` (writes `docs/env.lock`).

## 2. Dependencies

```bash
./tools/setup-env.sh --check      # reports missing packages, never installs silently
./tools/setup-env.sh --install     # optional: installs what is missing (needs root)
```

## 3. Build

```bash
./tools/fetch-submodules.sh        # third-party sources (gitlinks)
python3 tools/vpc2cmake.py --root . --out cmake/generated
./tools/build.sh                   # configure + build all stages, logs to logs/
```

Incremental builds for the renderer only:

```bash
ninja -C build-client libshaderapivulkan.so libmaterialsystem.so libengine.so
```

Build type is `Debug` with `-g`; symbols are never stripped.

## 4. Shader model

The renderer is built against the **shipped 2024** `stdshader_dx9.so`, which is the
module matching the shipped `.vcs` files. It is installed into the run tree by
`prepare-run-tree.sh`; to switch manually:

```bash
tools/use_shipped_shader_model.sh on     # 2024 shipped model (target state)
tools/use_shipped_shader_model.sh off    # tree-built model (debugging only)
```

## 5. Run tree and shader pack

```bash
./tools/prepare-run-tree.sh            # -> game_client/
```

This links the game content per entry (never Valve's prebuilt engine binaries),
links `build-client/*.so` and `launcher_main` into `bin/linux64`, writes
`hl2.sh`, installs the 2024 shader model, and — if `game_client/vulkan/manifest.json`
is absent — extracts the `.vcs` files from `hl2_misc_dir.vpk` and converts them to
SPIR-V with `tools/vcs_pack.py` (several minutes, ~1 GB). Options:

```bash
./tools/prepare-run-tree.sh --no-pack          # fast, links only
./tools/prepare-run-tree.sh /some/dir          # custom target
```

The pack is assembled from the game's own `.vcs` files, so it must be regenerated
per game install; it is never committed.

## 6. Run

```bash
cd game_client
LD_PRELOAD=../tools/steamstub/steamstub.so DISPLAY=:1 \
VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/radeon_icd.x86_64.json \
./hl2.sh -novid -shaderapi shaderapivulkan.so -windowed -w 640 -h 480
```

Software fallback (no GPU, standing-authorized for testing):

```bash
VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/lvp_icd.x86_64.json LP_NUM_THREADS=1
```

Validation layers are mandatory and on by default. `grep -c 'validation]\[ERROR'`
on the run log must be 0.

## 7. Verification gates

```bash
build-client/vk_matrix_test                  # matrix upload convention
ninja -C build-client vk_present_test && \
  build-client/vk_present_test               # swapchain + clear, 60 frames
```

Both must exit 0. `vk_present_test` writes its capture to `__tmp/tri.ppm` unless
`SE_VK_CAPTURE` points elsewhere.
